# Octacity Index

A map of the repositories that make up [Octacity](https://github.com/0ctacity).

Octacity is an open-source engineering community organized around long-term projects and eight main teams. This repository serves as the central directory for finding projects, teams, community resources, and organization infrastructure.

## Repository Types

Not every repository under Octacity is a software project.

### Project repositories

Software, developer tools, experiments, applications, libraries, and other maintained outputs.

Examples include Gora, fcage, Badbox, Octapowers, and Readme Studio.

### Team repositories

Repositories such as `.ARC`, `.LUCID`, and `.AEGIS` describe the focus and structure of Octacity teams.

They are places for team-level direction, discussions, and coordination rather than standalone software projects.

### Community repositories

Repositories such as `.github` and `membership` define how people participate in Octacity.

They contain organization-wide standards, governance, contribution processes, and membership information.

### Organization repositories

Repositories such as `brand`, `website`, `infrastructure`, and `index` support Octacity itself.

## Teams

Octacity is represented by eight main teams.

Team repositories document each team's focus, responsibilities, projects, and working structure.

| Team                                        | Focus                                                                                                                                                           |
| ------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Arc](https://github.com/0ctacity/.ARC)     | Applied AI and user-centric productization. ARC focuses on turning technical and AI capabilities into complete, usable products.                                |
| [Lucid](https://github.com/0ctacity/.LUCID) | Artificial intelligence, machine learning, data, evaluation, tooling, and the engineering required to make AI systems understandable, reproducible, and usable. |
| [Aegis](https://github.com/0ctacity/.AEGIS) | One of Octacity's eight main teams. Its specific focus area is still being defined.                                                                             |

Additional team repositories will be added here as the remaining Octacity teams are formed.

## Projects

| Project                                                                | Description                                                                                                                                                                                                                    |
| ---------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [Gora](https://github.com/0ctacity/gora)                               | Cross-platform preview runtime for strict, local `.gora` UI documents, with native application windows, Studio previews, headless sessions, deterministic captures, semantic inspection, and MCP-driven automation.            |
| [codebase-memory-mcp](https://github.com/0ctacity/codebase-memory-mcp) | Octacity's Zova-native fork of codebase-memory-mcp, providing persistent codebase knowledge graphs, structural and semantic search, cross-repository discovery, incremental indexing, and MCP tooling for coding agents.       |
| [Octapowers](https://github.com/0ctacity/octapowers)                   | Independent fork of Superpowers maintained by Octacity, providing a proportional software-development workflow for Codex and Claude Code with debugging, testing, verification, review, worktrees, and agent-driven execution. |
| [fcage](https://github.com/0ctacity/fcage)                             | Lightweight process sandbox for running untrusted or semi-trusted commands with explicit filesystem, executable, network, and capability restrictions using native sandboxing mechanisms across macOS, Linux, and Windows.     |
| [Badbox](https://github.com/0ctacity/badbox)                           | Deterministic bad-pattern detector that identifies suspicious structural patterns through static analysis and reports them to developers or coding agents without assuming every finding is automatically wrong.               |
| [Readme Studio](https://github.com/0ctacity/readme-studio)             | Web-based environment focused on writing, previewing, organizing, and assembling project README files.                                                                                                                         |
| [repozip](https://github.com/0ctacity/repozip)                         | Small Rust command-line tool for creating a ZIP archive of the committed state of the current Git repository using `git archive`.                                                                                              |
